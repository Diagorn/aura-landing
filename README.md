# aura-landing

Лендинг трекера эмоций **Aura**: Telegram-бот, внесение записей за пару секунд,
отслеживание эмоций и их факторов, активности, настроения и событий — плюс полная
кастомизация (свои эмоции, факторы, события).

## Стек

- React + Vite + TypeScript
- TailwindCSS v4 — тёмная и светлая темы (переключатель в шапке)
- framer-motion — анимации
- lucide-react — иконки

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка
npm run preview  # локальный просмотр сборки
```

## Конфигурация

- `AUTH_URL` — адрес приложения авторизации, на который ведут кнопки «Войти» и CTA.
  Задаётся переменной окружения `VITE_AUTH_URL` (см. `.env.example`).
  По умолчанию `/` — заглушка, ведущая на сам лендинг.

## Локализация

Все тексты вынесены в `src/i18n/` (сейчас — `ru`). Новый язык:
создать словарь по интерфейсу `Dictionary` из `src/i18n/types.ts`
и зарегистрировать его в `src/i18n/index.ts`.
